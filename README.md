# Lingo Brain

ADHD-friendly Telegram Mini App: Spanish from zero (A1) + English speaking (B1+).

- Live: https://aratacoder.github.io/lingo-app/
- Dark UI, 1 screen = 1 task, progress dots, hold-to-speak practice.
- 100% static (HTML/JS), hosted free on GitHub Pages. Progress is saved in the browser (localStorage).
